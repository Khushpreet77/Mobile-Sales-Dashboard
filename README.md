Mobile Sales Dashboard using Power BI
  Created an interactive Mobile Sales Dashboard in Power BI to analyze sales performance, revenue, and customer trends.
  Performed data cleaning and transformation for accurate reporting and analysis.
  Built custom calendar tables and managed relationships using Data Modeling.
  Used DAX functions for KPIs, MTD, QTD, YTD, and Same Period Last Year calculations.
  Designed interactive visuals using charts, slicers, cards, and filters for better business insights.
  Implemented edit interactions and dynamic filtering for improved dashboard usability.
  Published the dashboard on Power BI Service for online access and reporting.
